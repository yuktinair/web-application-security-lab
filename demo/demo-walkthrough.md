# Web Application Security Lab — Demo Walkthrough

## 1. Introduction

The Web Application Security Lab is a cybersecurity project developed using Python and Flask. The purpose of this project is to understand web application security, identify potential vulnerabilities, test security controls, and document remediation recommendations.

OWASP ZAP was used to scan the locally hosted application and identify potential security issues.

The project follows this workflow:

**Identify → Test → Fix → Verify → Document**

## 2. Project Objectives

The main objectives of this project are:

* Understand HTTP requests and responses.
* Learn about cookies, sessions, authentication, and authorization.
* Identify potential web application security vulnerabilities.
* Understand relevant OWASP Top 10 risks.
* Implement CSRF protection.
* Use OWASP ZAP for security testing.
* Document findings and recommend security improvements.
